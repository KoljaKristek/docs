Playbook. Mobile App Workflow
14 steps · 8 phases (incl. prereqs)
Flutter · Claude Code · App Store

From idea to App Store, fourteen steps at a time.

A chronological workflow grouped by phase. Expand any step for what it achieves, step-by-step instructions with prompts, and the artifact templates it produces — each viewable and downloadable.

This workflow combines two approaches: Spec-Driven Development (SDD) for Steps 1–10 — where requirements, design, and a frozen spec are fully established before any code is written and slice-based building executes from that spec — followed by Vibe Coding from Step 11 onward, where the polish phase invites looser, more intuitive iteration: testing surfaces issues, but also legitimate scope additions, minor user-flow tweaks, and design refinements that didn't reveal themselves until you held a working build.
